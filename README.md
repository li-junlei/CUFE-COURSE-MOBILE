# CUFE-COURSE Mobile

中央财经大学课程表移动端应用，基于 `Vue 3 + Tauri 2` 构建，支持 Android 打包。

## 当前版本

- `2.7.3`

## 本次更新重点

- 修复开学前桌面小部件错误显示第一周对应星期课表的问题，未开学时显示"距开学还剩X天"

## 常用命令

```bash
npm install
npm run build
npm run build:android
```

## Android Release 产物

- APK: `src-tauri/gen/android/app/build/outputs/apk/universal/release/cufe-course-v2.7.3-arm64-v8a-release.apk`
