# CUFE-COURSE Mobile

中央财经大学课程表移动端应用。登录教务系统一键导入课表与考试安排，支持多课表管理、桌面小组件、上课提醒与个性化外观。本应用面向 Android 手机，所有数据仅保存在你的设备本地。

## 当前版本

- `2.7.7`

### 本次更新

- 修复上课提醒依赖页面定时器、进入后台或锁屏后容易漏发的问题，Android 改由系统预先调度
- 按真实日期和课程周次安排提醒，翻看其他周不再影响提醒
- 修正连续课程提醒显示上一门课的问题，显示即将上的课程与完整起止时间
- 切换课表、修改课程或关闭提醒时清理旧通知，兼容旧版时间表配置
- 增加通知渠道与精确闹钟权限声明，通知发送失败时明确提示
- 新增 5 项提醒回归测试；完整变更见 [CHANGELOG.md](CHANGELOG.md)

## 主要功能

- 在线导入课表：登录学校教务系统，选择学年学期后自动抓取课表
- 多课表管理：同时保存多个学期的课表，支持切换、拖动排序、重命名、编辑与删除
- 在线更新课表：教务系统课程调整后重新抓取，并显示新增、删除、变化的统计
- 考试导入：从教务系统拉取考试安排，考试直接显示在课表对应日期
- 桌面小组件：在 Android 桌面查看当天课程；未开学时显示距开学剩余天数
- 上课提醒：课前推送通知，两种规则自动适配连续课程
- 个性化外观：自定义背景图，课程卡片可设置教师、地点显示与不透明度
- 备份与恢复：课表可导出为 JSON 文件，换机或重装后可从文件恢复
- 时间表方案：支持多套上下午上课时间方案，适配不同学期的作息

## 下载与安装

1. 前往 [Releases 页面](https://github.com/li-junlei/CUFE-COURSE-MOBILE/releases) 下载最新版 APK（arm64-v8a 架构，适用于近年主流 Android 手机）
2. 在手机上打开 APK 文件，允许安装未知来源应用后完成安装
3. 首次启动需要通知权限用于上课提醒，可按需允许或拒绝

## 快速上手

1. 打开应用，在个人中心使用学号和教务系统密码登录
2. 通过弹出菜单进入「课表管理」，点击「新建 / 在线导入」
3. 选择学年、学期，确认课表名称与开学日期后点击导入
4. 导入完成后即可查看课表，顶部会显示当前周次与学期状态

登录凭证保存在设备本地，下次打开应用自动恢复登录，无需重复输入。当前密码仅使用 Base64 编码，尚未接入系统安全存储。

## 功能说明

### 开学日期自动填写

导入课表时，应用会根据所选学年学期自动填写「第一周第一天」。日期来自应用内置的校历时间表，并定期从 GitHub 静默更新，无需任何操作。若某学年数据暂缺，则按「第一学期 9 月 1 日、第二学期次年 2 月 20 日所在周的周一」推测，此时请自行核对并修改。开学日期直接影响周次计算，如有出入可在课表编辑中随时修改。

### 上课提醒

在「设置」中开启后，应用会在课前推送通知：

- 下一节课与上一节不相邻时：课程开始前 15 分钟提醒
- 下一节课紧接上一节时：上一节结束前 3 分钟提醒

Android 上按课表的开学日期、实际课程周次和时间表，预先安排本学期的系统通知，锁屏或退出应用后仍可触发，不受界面正在查看的周次影响。切换课表、修改课程或关闭提醒会重新安排或取消待发送通知。考试不参与上课提醒。

开启时请允许通知权限；Android 12 及以上还需在系统设置中允许本应用的「闹钟和提醒」，否则系统可能延迟提醒。修改此权限后重新打开应用。请确认课表的「第一周第一天」和时间表正确。若厂商省电策略阻止提醒，请允许本应用后台运行；系统「强行停止」后需重新打开应用才能恢复。桌面端仍需保持应用运行。

### 桌面小组件

在 Android 桌面添加本应用的小组件（小组件列表中名为「显示当天课程进度」）即可查看当天课程。小组件数据由应用定期同步；学期开始前显示距开学剩余天数，开学后显示当天对应周次的课程。

### 课表备份

在课表管理中可将任意课表导出为 JSON 文件，文件可保存到任意位置。在新设备或重装后，通过「导入课表文件」选择之前导出的 JSON 即可恢复，适合换机迁移或未到校历更新时的手动备份。

### 外观自定义

在「外观设置」中可以：

- 更换或移除背景图（支持 JPG、PNG、WEBP）
- 开关网格辅助线、授课老师、上课地点显示
- 简化地点显示，隐藏「沙河校区」等前缀
- 调整课程卡片不透明度，平衡背景与可读性

## 数据与隐私

- 课表、配置与登录凭证保存在设备本地；登录和导入数据时会连接学校教务系统
- 当前保存的密码仅使用可逆的 Base64 编码，尚未接入系统安全存储
- 应用仅连接两类网络服务：学校教务系统（获取课表与考试）、GitHub（检查更新与获取校历时间表，均为静默进行）

## 常见问题

**上课提醒收不到怎么办？**

确认已在应用设置中开启上课提醒，并允许系统通知权限。Android 12 及以上请在系统设置中允许本应用的「闹钟和提醒」，修改权限后重新打开应用。核对课表的「第一周第一天」和时间表，必要时关闭再开启提醒以重新安排。被系统「强行停止」后需重新打开应用；厂商省电策略也可能影响投递。可先用「测试通知」检查即时通知是否正常。

**周次显示不对怎么办？**
周次由「第一周第一天」计算得出。进入课表管理，编辑对应课表，核对该日期是否与实际开学日期一致。

**检查更新没有反应？**
更新信息来自 GitHub，网络受限时可能暂时无法访问。可在「设置」中稍后手动重试，或直接前往 Releases 页面查看。

**为什么开学日期已经自动填好？**
这是 2.7.4 新增的校历时间表功能，日期来自维护者按学校校历维护的数据，通常与实际一致；仍建议导入时核对一眼。

**支持 iOS 或其他学校吗？**
目前仅支持 Android 与中央财经大学教务系统。

## 已知问题

- 登录密码仅作 Base64 编码，拿到本地凭证文件的人可还原密码，需接入系统安全存储
- 登录后的业务接口会从 HTTPS 降为 HTTP，课程、个人信息及会话信息存在明文传输风险
- 课表文件仍直接覆盖写入，保存过程中被终止可能导致文件损坏；配置文件已采用原子写入

## 从源码构建

适用于开发者：

```bash
# 环境要求：Node.js 18+、Rust、Android SDK/NDK（Tauri 2 Android 环境）
npm install
npm test                   # 上课提醒回归测试
npm run build              # 类型检查与前端生产构建
npm run tauri dev          # 桌面开发调试
npm run dev:android        # Android 真机调试
npm run build:android      # Android Release 构建
```

Rust 侧单元测试：

```bash
cd src-tauri && cargo test
```
